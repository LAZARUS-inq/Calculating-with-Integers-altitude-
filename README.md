# Calculating with Integers — Altitude 🏔️

A simple C++ console program that calculates the change in altitude between two points.

## What it does

Takes two altitude values as integer input from the user and computes the difference between them — representing vertical displacement (climb or descent).

## Example

```
Enter the first altitude: 1200
Enter the second altitude: 850
The change in altitude is -350 m.
```

## Concepts demonstrated

- Integer arithmetic and signed difference
- User input via `std::cin`
- Console output via `std::cout`
- Uniform initialization syntax (`int change{ alt2 - alt1 }`)

## Tech

- Language: C++
- Standard: C++11 or later
- Platform: Cross-platform (Windows / Linux / macOS)

## Why this exists

An early exercise in working with integers and basic arithmetic in C++. Understanding signed integer math is fundamental — the same logic appears in game dev for calculating distances, delta values, and positional offsets between objects.
